## Что делает программа

Сортирует данные из файла и записывает результат:

- **форматы**: `txt` (по одному значению в строке) и `csv` (сортировка
  по выбранному столбцу, строки переезжают целиком);
- **типы данных**: целые числа (`i`), числа с плавающей точкой (`f`),
  строки (`s`);
- **направление**: по неубыванию или по невозрастанию (`--reverse`);
- **запись**: в исходный файл (по умолчанию) или в новый файл (`--output`).

## Как запустить
Программа выполнена как консольное приложение. Для проверки работоспособности можно воспользоваться готовыми файлами для тестов test.txt, test.csv.
Пример запуска: python main.py -s test.txt -r -o result.txt -t i

Аргументы:

| Флаг | Назначение |
|------|------------|
| `-s, --source` | исходный файл (txt или csv), обязателен |
| `-o, --output` | выходной файл; если не задан — перезаписывается исходный |
| `-r, --reverse` | сортировать по невозрастанию |
| `-k, --key` | имя столбца csv для сортировки |
| `-t, --type` | тип данных: `i`, `f` или `s` |

При расширении имени файла отличном от txt/csv программа завершается с ошибкой
`ValueError`; аналогично — если столбца `key` нет в заголовке csv.
